PHASE 1: LOCAL POSTGRESQL SETUP (Same server as RTA)
═══════════════════════════════════════════════════════════════════════════════

Step 1: Create Database and User
───────────────────────────────────────────────────────────────────────────────

Connect to PostgreSQL as postgres user:

    psql -U postgres

Then run these commands:

    -- Create database
    CREATE DATABASE highlowjack;
    
    -- Create user
    CREATE USER highlowjack_user WITH PASSWORD 'your_secure_password_here';
    
    -- Grant privileges
    GRANT ALL PRIVILEGES ON DATABASE highlowjack TO highlowjack_user;
    
    -- Connect to the database
    \c highlowjack
    
    -- Grant schema privileges
    GRANT ALL ON SCHEMA public TO highlowjack_user;
    GRANT ALL PRIVILEGES ON ALL TABLES IN SCHEMA public TO highlowjack_user;
    GRANT ALL PRIVILEGES ON ALL SEQUENCES IN SCHEMA public TO highlowjack_user;
    
    -- Exit
    \q

───────────────────────────────────────────────────────────────────────────────

Step 2: Run Schema Creation
───────────────────────────────────────────────────────────────────────────────

Run the schema.sql file:

    psql -U highlowjack_user -d highlowjack -f schema.sql

This will:
- Create all tables
- Add seed data (initial players)
- Add Preezbob's signature quips
- Create useful views

───────────────────────────────────────────────────────────────────────────────

───────────────────────────────────────────────────────────────────────────────

Step 1: Inject PlayerService into Controller
───────────────────────────────────────────────────────────────────────────────

In HighLowJackController.java:

    @Autowired

───────────────────────────────────────────────────────────────────────────────

Step 2: Update Stats After Match
───────────────────────────────────────────────────────────────────────────────

In continueGame() after match winner detected:

    // Update all player stats
    if (game.isTeamMode()) {
        for (Team team : game.getTeams()) {
            for (String playerName : team.getPlayerNames()) {
                boolean won = team.getName().equals(matchResult.getWinner());
                int setsWon = matchResult.getFinalSetWins().getOrDefault(team.getName(), 0);
                playerService.updateMatchStats(playerName, won, setsWon);
            }
        }
    } else {
        for (String playerName : game.getPlayerNames()) {
            boolean won = playerName.equals(matchResult.getWinner());
            int setsWon = matchResult.getFinalSetWins().getOrDefault(playerName, 0);
            playerService.updateMatchStats(playerName, won, setsWon);
        }
    }

───────────────────────────────────────────────────────────────────────────────

Step 3: Track Points During Rounds
───────────────────────────────────────────────────────────────────────────────

In continueGame() after round scoring:

    // Record point wins
    for (String category : new String[]{"High", "Low", "Jack", "Game"}) {
        String winner = results.getRoundPointWinner(category);
        if (winner != null) {
            // In team mode, record for actual player, not team
            String playerName = game.isTeamMode() ? 
                results.getRoundPointPlayer(category) : winner;
            playerService.recordPoint(playerName, category);
        }
    }
